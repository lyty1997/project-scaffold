# Tool Failures

Read the error and identify its cause: invocation, path, project, dependency, permission, sandbox, network, or service. Correct the cause before retrying; unchanged retries need evidence of a transient failure and a bounded limit.

Use an equivalent available tool when appropriate, retaining verification coverage. Follow environment authorization rules for restricted actions. If blocked, report the missing step, evidence, impact, and next action; continue independent authorized work. Store reusable fixes in [Known Issues](../known-issues.md).
