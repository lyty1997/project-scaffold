# 语言与本地化

状态：active

最近更新：2026-09-06

适用范围：仓库公开文档、Agent 指令、第一方源码注释与消息、公开 UI 文案和生成图表

## 决策

英文是项目默认语言和主要维护语言。持续维护的中文译本仅限项目说明和设计文档：`README.md`、`SCAFFOLD.md` 以及 `docs/` 下的 Markdown。英文文档保留原文件名，中文译本放在同目录并使用 `-zh.md` 后缀。

Agent 指令和贡献协作流程只维护一份英文版本：`AGENTS.md`、`CLAUDE.md`、`CONTRIBUTING.md`、`codex-rules/`（含索引和已知问题）、`.claude/rules/`、第一方 Skill 指令以及 PR 模板。不得创建翻译副本或另设翻译规则目录，避免重复指令进入模型上下文，也避免维护等价的多套提示词。

每组保留的双语文档在靠近顶部的位置互相链接。英文文档默认链接其他英文文档；若目标存在中文译本，中文文档应链接对应的 `-zh.md`，仅维护英文的指令则链接规范英文文件。命令、标识符、路径、协议名、商标和历史事实保持准确的技术拼写。

## 真相源与同步契约

- 英文文档是当前行为、设计和公开表达的规范真相源。
- 修改成对的项目文档时，必须在同一次变更中同步更新两种语言。中文文件是持续维护的译本，不是归档。
- 保留上述配对范围内的现有中文项目说明和设计文档；删除中文指令和协作流程副本、对应语言切换链接以及要求重建这些副本的规定。
- 新增第一方文档使用英文，仅上述项目文档配对范围要求中文译本；生成内容、vendored 内容和已明确记录为语言无关的内容继续适用现有例外。
- `docs/README.md` 只索引规范英文文档并链接 `docs/README-zh.md`；中文入口只索引对应中文文档，不在英文索引逐份重复中文译本。
- `check:localization` 校验保留的项目文档成对互链，并拒绝仅维护英文的指令出现中文副本，包括大写 `-ZH.md` 变体；默认英文文本扫描和功能数据例外继续生效。

## 代码、UI 与生成产物

- 第一方代码注释、CLI 提示、诊断信息、fixture 描述、PR 模板和公开 UI 文案使用英文。
- 分支名与 Conventional Commit 主题使用英文。提交钩子校验 `<type>(<scope>): <English subject>`，不再要求重复的中文主题。
- `public/index.html` 声明英文，并默认展示英文占位文案。
- Archify Typed JSON 的作者内容使用英文，`meta.locale` 设为 `"en"`；PlantUML 围栏块和生成 SVG 标签也使用英文，因此 HTML、PNG、SVG 生成物统一展示英文图中文字。
- 中文文档复用英文图表产物；仓库不维护第二套中文拓扑或重复的图表产物家族。

## 边界

Vendored 第三方实现文件保持与固定上游契约的字节兼容，除非另有经过审查的 vendor 升级任务。因此 locale 字典、品牌目录、多语言解析 fixture、用于校验 `-zh.md` 内容的中文契约词和生成 HTML 可以把中文作为可选 locale 或测试边界的功能数据保留下来；它们不是第一方文案或注释，也不会改变英文默认入口。围绕 vendored 行为新增的第一方注释仍使用英文。历史记录只做忠实翻译，不改写成与当时状态不符的叙述。

本次本地化变更不新增用户数据收集、遥测、第三方运行时服务或网络依赖。
